# SkillsCheck 002 — Paragraph Typography

An interactive assessment for practicing HTML paragraphs and CSS typography.

## Live Demo

https://freetimezp.github.io/skillscheck-002-paragraph/

## Related Lesson

School 002 — Paragraph Typography

https://github.com/freetimezp/school-002-paragraph

## Topics

- HTML paragraph element: `<p>`
- Paragraph structure and semantics
- CSS `font-size`
- CSS `font-family`
- CSS `font-weight`
- CSS `line-height`
- CSS `max-width`
- CSS `margin` and `padding`
- Responsive text width
- Readable line spacing and text contrast

## Features

- 20 randomized questions
- Randomized answer options
- Radio buttons and checkboxes
- HTML and CSS snippets in every question
- Instant answer validation
- Correct and incorrect answer highlighting
- Explanations for every question
- Progress bar and live score
- Final score and accuracy
- Restart with a new randomized order
- Responsive design
- Reduced-motion support
- Vanilla JavaScript with no build tools required

## Run Locally

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Complete all 20 questions.
4. Review the explanations and restart to practice again.
